# v0.1.0-preview.1 · 家庭互动试玩快照

日期：2026-10-10。体验版本：layout-20261009-r10。

## 使用

[手机/电脑直接试玩](https://ning-and-far-d4gnalnk55f9133e8-1251364700.tcloudbaseapp.com/play/?v=layout-20261009-r10)。云站不依赖作者电脑开机；首次测试域名提示请点“确定访问”。支持独立屏幕操作。

英语提供词汇、听力、口语、翻译和我的单词五入口。口语错误收录目标词，每题一次，累计两错进入易错，连续三对移出；静音、识别失败或取消不计错。参考分来自识别文本，不是音素专业测评。

鼓游戏有小星星、宝贝宝贝、生长吧、红星闪闪、小白兔白又白，三档难度、五背景、触屏鼓垫、暂停和本机成绩。新歌逐拍谱制作流程在originals/drumRhythmGame/timing。

成语85条题库随机轮换，三关24题，拼字/补字/释义三玩法，提示免费、错误可重试、奖励与场景。统一视口框架覆盖菜单、弹层和结算，支持短屏与横屏滚动。

## 开发与部署

Node24.21.0、pnpm12.3.4。执行根pnpm install --frozen-lockfile，再pnpm --dir originals/drumRhythmGame install --frozen-lockfile，最后pnpm dev:web；打开/play/。生产Web执行pnpm --filter @kele/web build。

源码含originals依赖快照，不要求原作者D盘目录。生成的apps/web/public/legacy不入Git；首次构建从源码生成。语音服务配置由使用者管理；EnglishLearning/.env.example只有占位符，真实.env不会入包。HTTPS录音、安全权限、服务费用和限流需在自己部署时设置。模型文件未分发。

## 验收与限制

六种Edge模拟视口从真实/play入口原生触摸通过，补验短屏鼓自然结算返回、英语暂停/重玩与成语奖励下一题；详见本目录验收文档。自动化不等于iPhone Safari/安卓真机或实体BLE验收。

家庭数据与词库目前仅当前浏览器保存。小程序正式版、Agent办事和家庭云同步未完成。本版本用于分享体验，不宣称平台整体上线。老伙计根站与companion后台独立保留。
